# 🧍 Human Pose Detection using Machine Learning

## 📌 Project Overview

Human Pose Detection is a **Machine Learning and Computer Vision-based project** that detects and tracks human body movements from images, videos, and real-time webcam input.

The main goal of this project is to enable computers to understand human posture by identifying important body key points such as **head, shoulders, elbows, wrists, hips, knees, and ankles**.

The system processes visual data and generates a human skeleton structure by connecting detected body landmarks. This technology can be used in various fields such as fitness monitoring, healthcare, sports analysis, and human-computer interaction.

---

  🎯 Objectives

- Detect human body poses from images and videos
- Identify important human body landmarks
- Analyze human posture and movements
- Provide real-time pose estimation
- Visualize detected body joints using skeleton mapping

# 🔍 How the System Works

### 1. Input Collection
The system takes input from images, videos, or a live webcam feed.

### 2. Image Processing
The input frames are processed using computer vision techniques to improve detection quality.

### 3. Feature Extraction
Important features and body landmarks are extracted from the detected human image.

### 4. Pose Detection
The machine learning model identifies different body key points such as shoulders, elbows, knees, and ankles.

### 5. Skeleton Visualization
The detected landmarks are connected to create a human skeleton structure, representing the person's pose.
